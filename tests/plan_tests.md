
# Plan de tests - Projet fil rouge

**Issue associée :** #1 - Finalisation du projet

## 1. Objectif

Ce document présente les différents tests à réaliser
afin de vérifier le bon fonctionnement du projet avant
sa validation finale.

## 2. Stratégie de test

Les tests seront organisés selon les catégories suivantes :

- Tests unitaires : vérifier le fonctionnement individuel
  des différentes fonctions ou composants.
- Tests fonctionnels : vérifier que les fonctionnalités
  répondent aux besoins définis.
- Tests d'intégration : vérifier que les différents
  composants fonctionnent correctement ensemble.
- Tests de validation : vérifier que le projet répond
  aux objectifs initiaux.
